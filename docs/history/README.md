# Historical Documentation

This directory contains historical implementation context that is useful for tracing decisions but is **not** part of the default current-truth context for Codex/AI agents.

Put material here when it is mainly about:

- completed refactor phases;
- superseded task plans;
- old production/deployment snapshots;
- experiments that are no longer active architecture;
- historical bug investigations;
- design decisions whose result is already reflected in current architecture/business docs.

Do not put current execution rules here. Current truth belongs in:

- `AGENTS.md`
- `docs/ARCHITECTURE.md`
- `docs/BUSINESS_RULES.md`
- `docs/AI_INDEX.md`
- `HANDOFF.md`

Agents should read history only when a task requires origin/why/previous-attempt context.

`CODEX_TASKS.md` remains at repository root for compatibility with existing history, but should be treated as legacy task material rather than mandatory context. It may be split/migrated here in a later documentation-only change.

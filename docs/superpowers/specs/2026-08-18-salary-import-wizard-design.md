# 工资表三步导入向导设计

## 目标

工资条管理打开时只展示管理工作台；导入工资表采用“上传、预览、设置”三步向导，完成后进入该工资表的发送管理界面。

## 默认页状态

- `activeBatchId` 只决定当前月份显示的工资表与员工表格。
- `detailBatchId` 只决定右侧详情抽屉是否打开，初始值为空。
- 加载、切换月份或刷新列表不得修改 `detailBatchId`。
- 仅“查看发送”和显式点击工资表打开详情抽屉。

## 导入步骤

1. 上传 Excel：选择文件、发薪月份、工资条标题和通讯录匹配字段；点击下一步后只创建服务器内存预览。
2. 预览表格数据：水平可滚动表格显示来源字段与行；汇总行显示为“汇总行，不导入”，不进入通讯录匹配和创建数据。异常人员仍可选择企业通讯录成员。点击下一步进入设置。
3. 设置工资条：选择实发金额字段、空值隐藏字段、员工反馈/确认、提示文案和预览主题。点击完成才提交预览并创建工资表。

## 完成页

成功提交后关闭向导、刷新工资表列表、切换到新工资表，并在工资条管理页显示员工发送表格。单人发送与 DING 通道不在本次界面改造中伪装为已可用能力。

## 可观测性与错误

- 上传预览、汇总行过滤、人工匹配和最终提交的审计记录均包含预览 ID、行数及忽略汇总行数，不记录薪资值。
- 任一阶段错误保留在该步骤，用户可修正并重试；关闭向导会丢弃仅存于内存的预览。

## 验收条件

1. 页面首次打开没有详情抽屉或遮罩层。
2. 预览步骤显示原始 Excel 字段及汇总行忽略说明，且下一步不创建工资表。
3. 设置步骤完成后才创建工资表，并直接展示该批次的发送管理表格。
